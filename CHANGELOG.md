# Changelog

All notable changes to SaveZero will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Comprehensive README improvements with problem-first approach
- CHANGELOG.md for tracking version history
- CONTRIBUTING.md for contributor guidelines
- SECURITY.md for security policy
- Issue templates for bug reports and feature requests
- GitHub Actions CI workflow
- Demo script guidance document

### Changed
- README structure to prioritize user benefits over technical details
- Repository description for better discoverability

## [0.1.0] - 2026-09-20

### Added
- Enhanced features and documentation improvements
- `--url` CLI option for custom saved collection URLs
- Improved shortcode extraction for flexible URL path structures

### Changed
- Updated README with additional usage examples
- Improved help text with URL examples

## [0.0.3] - Earlier

### Added
- Improved launcher setup and usage documentation
- Better cross-platform support for Windows and Unix systems

## [0.0.2] - Earlier

### Fixed
- Packaging and runtime reliability improvements

## [0.0.1] - Initial Release

### Added
- Initial SaveZero implementation
- Dual execution modes (API and UI)
- Self-healing browser recovery
- Tiered milestone throttling
- Dynamic selector resolution
- Zero-credential authentication via Chrome profile
- Cross-platform launcher scripts (run.bat, run.sh)
- Basic documentation
