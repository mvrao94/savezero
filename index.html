Why SaveZero?

⚡

Lightning Fast

Clear 2,000+ saved posts without clicking "Unsave" thousands of times. API mode processes posts efficiently with minimal overhead.

🔒

100% Local & Secure

Runs entirely on your machine using your Chrome profile. Zero credentials stored, no data sent anywhere except Instagram.

🔄

Self-Healing Recovery

Automatically recovers from browser crashes, connection drops, or system sleep. Resumes right where it left off.

⏱️

Smart Rate Limiting

Tiered cooldowns: micro-breathers every 40 posts, 15-min rest every 1,000 posts, 1-hour rest every 2,000 posts.

🎯

Dynamic Selectors

Works around Instagram's obfuscated CSS classes using relative XPaths and ARIA attributes. Adapts to platform changes.

🌐

Cross-Platform

Works on Windows, macOS, and Linux. Python 3.8+ supported with comprehensive CI testing.

Quick Start

1. Clone the Repository

git clone https://github.com/mvrao94/savezero.git
cd savezero

2. Install Dependencies

pip install -r requirements.txt

3. Run SaveZero

# On Windows:
.\run.bat --username your_instagram_username

# On Linux/macOS:
./run.sh --username your_instagram_username

# Or directly with Python:
python cleaner.py --username your_instagram_username

Or Install as Package

pip install git+https://github.com/mvrao94/savezero.git
savezero --username your_instagram_username

First Run: SaveZero will open Chrome and pause at an authentication gate. Log into your Instagram account and complete 2FA. The script will automatically detect successful authentication and begin clearing.
